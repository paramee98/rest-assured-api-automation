# Rest Assured API Automation Framework

This repository contains a robust automation framework for testing RESTful APIs. It is built using **Java** and **Rest Assured**, following best practices such as the design patterns, POJO classes for payload management, and SpecBuilder for request/response modularity.

## 🚀 Key Features
* **POJO Serialization/Deserialization:** Utilizes Java objects to handle complex JSON requests and responses.
* **Authentication:** Implementations for OAuth 2.0 and API Key-based security.
* **Modular Design:** Centralized reusable methods and Spec Builders to reduce code duplication.
* **Real-world Scenarios:** End-to-end test cases for E-commerce workflows and Jira API integrations.

## 📂 Project Structure
* `files/`: Contains test scripts (Jira, Ecom, OAuth) and reusable utility methods.
* `pojo/`: Defines the data models (Java Beans) used for API request and response bodies.

## 🛠️ Prerequisites
* Java JDK 11 or higher
* Maven
* IDE (Eclipse)
